总体架构：本地服务 + 浏览器界面

单 exe 双击启动 → 自动提权 → 本地 HTTP 服务 → 浏览器打开 Web 界面

💻 客户电脑（Windows 10/11）
📦 DiskClean.exe
① 双击启动
② 检测权限 → 自动弹 UAC 提权重启自身
③ 启动本地 HTTP 服务
④ 自动打开浏览器
🌐 浏览器页面（localhost）
⑤ 输入密钥解锁清理功能
⑥ 点击扫描 → 实时进度
⑦ 勾选项目 → 一键清理
🔧 后端（Node，内嵌在 exe 中）
· HTTP 服务（含随机 token，仅本机可访问）
· 密钥验证（HMAC-SHA256 离线验证）
· 编排 PowerShell 子进程执行扫描/清理
· 解析结果返回前端
⚙️ PowerShell 子进程（系统能力层）
· 目录大小扫描（递归统计）
· 回收站清空（Shell COM）· Windows\\Temp 清理
· 系统盘空间查询 · 按需扩展（DISM 等）
🖥️ 你的电脑（生成密钥）
🔑 KeyGen（密钥生成器，Node 脚本）
输入客户备注 → 输出密钥
如：DKC-XXXX-XXXX-XXXX-XXXX
📤 通过微信/QQ 发给客户
客户在界面粘贴密钥 →
离线验证通过 → 解锁清理
密钥内嵌同一把「主密钥」（签发密钥），验证密钥在 exe 内离线完成，全程无需联网

数据流

双击 exe → UAC 提权 → 启动服务 → 打开浏览器
→ 前端 POST /scan → Node 启动 PowerShell 扫描（多目录并行）→ 返回分类结果
→ 前端展示 → 用户输入密钥 → POST /verify → HMAC 验证 → 解锁
→ 用户勾选 → POST /clean → Node 编排 PowerShell 清理 → 返回释放空间
→ 前端展示结果 🎉
