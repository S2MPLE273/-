# DiskClean Agent

绿色单 exe 磁盘清理工具：服务方远程协助客户时，客户下载工具、输入服务方签发的密钥（默认 1 天有效期），自助完成任意磁盘的扫描与清理。纯本地运行、无广告、无上传、删除即卸载。

## 最新版：v0.2.4（2026-08-16）

### 本次更新

- **修复"先无效、过会儿又有效"**：密钥内嵌签发时刻（分钟精度），原验证要求本机时钟不早于签发时刻——签发机时钟略快于客户机（秒级偏差即可触发）就会误报无效。现加入 24 小时时钟容差（早于签发时刻 24h 内可通过），到期时刻保持严格不延长
- **密钥设备绑定（可选）**：keygen 新增"客户设备码"输入——客户在程序界面复制本机设备码发给服务方，服务方填写后生成的密钥仅该设备可用，其他设备提示"此密钥已绑定其他设备"。不填设备码则任意设备可用（与旧版相同）
- keygen 显示本机时间（密钥按本机时钟签发，便于发现时钟不准）

## 使用方法

| 文件 | 给谁 | 用法 |
|---|---|---|
| `dist/DiskCleanAgent.exe` | 客户 | 双击 → UAC 提权 → 浏览器自动打开 → 选盘扫描（免费）→ 输密钥 → 勾选清理（界面显示本机设备码，绑定密钥需先发给服务方） |
| `dist/keygen.html` | 服务方 | 双击打开 → 输管理密码 → 填客户备注 + 有效期（+ 可选客户设备码）→ 生成密钥（含历史记录） |

## 特性

- 零运行时依赖单 exe（Node 24 SEA 打包），离线 HMAC 密钥验证（客户机无需联网）
- 密钥有效期（签发时刻起精确 N×24 小时，1/2/3/7/30 天可选，24h 时钟容差）+ 时间回拨防护 + 可选设备绑定（设备码烙入密钥，其他设备提示已绑定）
- 扫描免费、清理需密钥；失败诊断（安全软件检测 + 建议 + 单项目重试）
- 非系统盘白名单底线：仅可清该盘回收站（防误删客户数据）

## 已知限制

- exe 未做代码签名：客户机 SmartScreen 会提示"未知发布者"，需点"更多信息 → 仍要运行"
- keygen 历史记录存于生成密钥的那台电脑的浏览器（localStorage），换电脑/清浏览器数据会丢
