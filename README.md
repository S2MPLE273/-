# DiskClean Agent

绿色单 exe 磁盘清理工具：服务方远程协助客户时，客户下载工具、输入服务方签发的密钥（默认 1 天有效期），自助完成任意磁盘的扫描与清理。纯本地运行、无广告、无上传、删除即卸载。

## 最新版：v0.2.3（2026-08-16）

### 本次更新

- **修复回收站清理必失败**：原实现调用 `SHEmptyRecycleBin`，在提权（管理员）进程中因跨完整性 Shell 隔离必然返回 E_UNEXPECTED（实测 Win11 26200，非提权对照组正常）。现改为直接删除所选盘 `$RECYCLE.BIN` 内容，保持"仅清所选盘"语义。桌面回收站视图可能延迟刷新（打开回收站即恢复）
- **清理失败项显示原始错误**：失败项目现在同时显示诊断建议与原始错误信息，便于定位问题

## 使用方法

| 文件 | 给谁 | 用法 |
|---|---|---|
| `dist/DiskCleanAgent.exe` | 客户 | 双击 → UAC 提权 → 浏览器自动打开 → 选盘扫描（免费）→ 输密钥 → 勾选清理 |
| `dist/keygen.html` | 服务方 | 双击打开 → 输管理密码 → 填客户备注 + 有效期 → 生成密钥（含历史记录） |

## 特性

- 零运行时依赖单 exe（Node 24 SEA 打包），离线 HMAC 密钥验证（客户机无需联网）
- 密钥单机绑定 + 有效期（签发时刻起精确 N×24 小时，1/2/3/7/30 天可选）+ 时间回拨防护
- 扫描免费、清理需密钥；失败诊断（安全软件检测 + 建议 + 单项目重试）
- 非系统盘白名单底线：仅可清该盘回收站（防误删客户数据）

## 已知限制

- exe 未做代码签名：客户机 SmartScreen 会提示"未知发布者"，需点"更多信息 → 仍要运行"
- keygen 历史记录存于生成密钥的那台电脑的浏览器（localStorage），换电脑/清浏览器数据会丢
